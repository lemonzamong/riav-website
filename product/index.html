Iruvy Go

사용자는 길을 찾고,
기관은 길을 개선합니다.

Iruvy Go는 사용자 안내 앱, 운영자 공간 관리, 기관용 검증 지표를 한 흐름으로 연결합니다.

User journey

목적지를 고르는 순간부터 도착까지.

진료실, 상담실, 민원창구처럼 주소로 찾기 어려운 실내 목적지를 검색하거나 말로 입력합니다.

  1. 목적지 선택
    현재 건물의 실제 방문 지점을 탐색
  2. 위치 확인
    실내 신호와 스마트폰 움직임으로 현재 위치 추정
  3. 경로 안내
    큰 글자, 화살표, 음성, 진동으로 다음 행동 전달
  4. 도착·이탈 확인
    경로에서 벗어나면 다시 계산하고 목적지 도착 확인

Multimodal guidance

한 가지 감각에만 의존하지 않습니다.

VOICE

음성 안내

화면을 보지 않아도 다음 방향과 남은 거리를 들을 수 있도록 핵심 지시를 짧게 전달합니다.

HAPTICS

진동 안내

소리를 듣기 어렵거나 주변 소음이 큰 상황에서도 변화 지점을 놓치지 않도록 보조합니다.

VISUAL

큰 화면 안내

방향, 거리, 층 정보를 높은 대비와 큰 글자로 보여 주어 빠르게 판단하도록 돕습니다.

RECOVERY

경로 이탈 대응

사용자가 계획 경로에서 벗어나면 현재 위치를 다시 판단해 안내를 이어갑니다.

For facility teams

공간은 바뀌어도
안내는 멈추지 않도록.

운영자는 출입구, 목적지, 분기점, 엘리베이터와 접근성 동선을 확인하고 변경 사항을 반영합니다.

01

공간 스캔

주요 동선과 공간 구조를 기록합니다.

02

경로 검수

자동 생성 결과를 사람이 확인합니다.

03

목적지 게시

사용자에게 필요한 지점을 공개합니다.

04

변경 반영

공사와 이전에 맞춰 공간 정보를 갱신합니다.
