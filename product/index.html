진료실·민원창구·상담실처럼 주소로 찾기 어려운 실내 목적지를 고르면, Iruvy Go는 현재 위치를 추정하고 음성·진동·큰 화면으로 다음 행동을 안내합니다. 화면을 계속 내려다보지 않아도 분기점과 층간 이동을 놓치지 않도록 설계했습니다.

User journey

목적지를 고르는 순간부터
도착까지 이어집니다.

입력, 실시간 안내, 도착 확인의 세 단계로 이동을 끊기지 않게 연결합니다. 각 단계에서 사용자가 실제로 하는 행동을 기준으로 화면과 안내를 구성했습니다.

01
입력 · DESTINATION

가려는 곳만
고르면 됩니다.

건물 내부의 실제 방문 지점을 검색하거나 말로 입력해, 주소로 찾기 어려운 목적지를 바로 지정합니다.

  • 실제 방문 지점 검색
  • 음성으로 목적지 입력
  • 자주 가는 곳 저장
02
안내 · GUIDANCE

다음 행동을
계속 알려줍니다.

실내 신호와 스마트폰 움직임으로 현재 위치를 추정하고, 방향과 남은 거리를 음성·진동·큰 화면으로 전달합니다.

  • 실내 신호 기반 위치 추정
  • 음성·진동·화면 동시 안내
  • 층간 이동·분기점 안내
03
확인 · ARRIVAL

길을 놓쳐도
다시 이어집니다.

계획 경로에서 벗어나면 현재 위치를 다시 판단해 안내를 이어가고, 목적지 도착을 확인합니다.

  • 경로 이탈 시 재탐색
  • 목적지 도착 확인
  • 이동 기록으로 개선

Multimodal guidance

한 가지 감각에만
의존하지 않습니다.

사용자의 상황과 감각 조건이 달라도 다음 행동을 놓치지 않도록, 안내를 음성·진동·화면으로 겹쳐 제공합니다.

VOICE

음성 안내

화면을 보지 않아도 다음 방향과 남은 거리를 들을 수 있도록 핵심 지시를 짧게 전달합니다.

HAPTICS

진동 안내

소리를 듣기 어렵거나 주변 소음이 큰 상황에서도 변화 지점을 놓치지 않도록 보조합니다.

VISUAL

큰 화면 안내

방향, 거리, 층 정보를 높은 대비와 큰 글자로 보여 주어 빠르게 판단하도록 돕습니다.

RECOVERY

경로 이탈 대응

사용자가 계획 경로에서 벗어나면 현재 위치를 다시 판단해 안내를 이어갑니다.

For facility teams

공간은 바뀌어도
안내는 멈추지 않도록.

운영자는 스마트폰으로 공간을 등록하고, 자동 생성된 경로를 검수해 게시하며, 공사와 이전에 맞춰 갱신합니다. 사용자 안내와 기관 리포트가 같은 공간 데이터에서 이어집니다.

  • 01
    공간 스캔

    출입구·목적지·분기점·엘리베이터 등 주요 동선과 구조를 스마트폰으로 기록

  • 02
    경로 검수

    자동 생성된 경로를 사람이 확인하고 접근성 동선을 보정

  • 03
    목적지 게시

    사용자에게 필요한 지점만 골라 공개

  • 04
    변경 반영

    공사·이전에 맞춰 공간 정보를 갱신해 안내를 유지
