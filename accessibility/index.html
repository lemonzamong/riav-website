Accessibility statement

웹 접근성 선언

Iruvy는 사람·공간·사물의 상호작용을 데이터화해 운영 의사결정과 실행을 개선하는 회사로서 웹사이트도 가능한 한 많은 사용자가 스스로 이용할 수 있어야 한다고 봅니다.

목표

WCAG 2.2 AA를 실무 기준으로 삼아 키보드 탐색, 명확한 제목 구조, 충분한 대비, 화면 확대, 움직임 축소, 설명형 링크와 양식 레이블을 제공합니다.

현재 제공하는 기능

  • 본문 건너뛰기 링크와 의미 있는 문서 랜드마크
  • 키보드로 조작 가능한 메뉴와 문의 양식
  • 명확한 초점 표시와 움직임 축소 설정
  • 제품 화면의 핵심 내용을 설명하는 대체 텍스트
  • 작은 화면과 200% 확대에서도 재배치되는 레이아웃

알려진 제한

제품 화면 이미지 안의 모든 시각 정보가 대체 텍스트에 포함되지는 않습니다. 핵심 사용 흐름은 이미지 주변의 본문에서도 동일하게 설명합니다. 실제 앱과 PoC 환경의 접근성은 웹사이트와 별도로 계속 검증합니다.

점검 범위

최근 점검일은 2026년 7월 16일입니다. 공개 페이지의 제목 구조·링크·이미지 대체 텍스트와 양식 레이블을 자동 검사하고, Chromium 환경의 390px·1440px 화면에서 재배치와 가로 넘침을 확인했습니다. 키보드 전체 이동과 화면 읽기 프로그램을 사용한 시나리오 점검은 아직 완료하지 않았습니다.
