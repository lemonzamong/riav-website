The last indoor distance

GPS는 건물 입구에서 끝납니다.
사람의 이동은 끝나지 않습니다.

병원 진료실, 공공기관 민원창구, 복지관 상담실, 전시장 부스처럼 방문자가 정말 가야 하는 곳은 건물 안에 있습니다.

실내에서 길을 잃으면 방문자는 계속 도움을 요청하고, 기관은 안내와 동행에 같은 시간을 반복해서 씁니다. Iruvy는 이 마지막 실내 이동을 사용자의 독립 이동과 기관의 운영 개선으로 연결합니다.

One journey, multiple senses

화면을 계속 보지 않아도 길을 놓치지 않도록.

목적지를 말하거나 선택하면 현재 위치에서 경로를 계산하고, 이동 중에는 음성·진동·큰 화면 안내를 함께 제공합니다.

  1. 목적지 선택
    진료실, 상담실, 민원창구처럼 실제 방문 지점을 검색
  2. 현재 위치 확인
    실내 신호와 스마트폰 센서를 바탕으로 위치를 추정
  3. 다중 감각 안내
    분기점과 층간 이동을 음성·진동·화면으로 전달
  4. 도착 확인
    목적지 도착과 경로 이탈을 확인하고 다시 안내
