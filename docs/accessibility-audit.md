# 웹 접근성 감사

상태: 구현 후 재검사 완료

## 기준선 강점

- 한국어 문서 언어 지정
- 본문 건너뛰기 링크
- 의미 있는 제목 요소
- 초점 표시
- 움직임 축소 설정
- 기본 HTML 기반 모바일 메뉴

## 완료한 수정

| 항목 | 심각도 | 상태 |
|---|---:|---|
| 실제 문의 양식의 레이블·오류 상태가 없음 | Major | 레이블, 필수 상태, 실시간 상태 문구 추가 |
| 모바일 메뉴 열린 상태와 닫기 흐름이 제한적 | Major | 버튼, `aria-expanded`, Escape 닫기, 본문 잠금 추가 |
| 이미지 내부의 중요한 글자를 대체 설명만으로 충분히 전달하지 못함 | Major | 구체 대체 설명과 동일한 주변 본문 제공 |
| 색상 대비 수치 검증 기록 없음 | Major | 주요 조합 4.88:1 이상 확인 |
| 접근성 선언 페이지 없음 | Minor | `/accessibility/` 추가 |
| 보조 페이지의 모바일 탐색 검증 부족 | Minor | 390px에서 8개 주요 경로 가로 넘침 없음 확인 |

## 검사 결과

- 9개 페이지 모두 `lang="ko"`, 한 개의 `h1`, 본문 건너뛰기 링크를 가짐
- 제품 이미지 3개에 구체 대체 설명 제공
- 모바일 메뉴 열림 상태: `aria-expanded=true`, 메뉴 표시, 본문 스크롤 잠금 확인
- 문의 빈 제출: 첫 필수 항목으로 초점 이동, `role=status` 오류 문구 출력 확인
- 콘솔 경고와 오류 0건
- 움직임 축소 설정에서 전환 제거
- 최소 확인 대비: 일반 텍스트 4.88:1, 주요 보라색 5.04:1 이상

## 남은 제한

실제 화면 읽기 소프트웨어별 발음과 iOS·안드로이드 앱 접근성은 웹 브라우저 검사와 별도임. 공개 전 VoiceOver와 TalkBack 실제 기기 확인을 권장함.
