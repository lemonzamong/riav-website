# 외부 차단 사항

현재 사이트 구현과 검증을 멈추게 하는 차단 사항은 없음.

## 배포 차단

- 2026-07-10 Sites 비공개 배포를 시도했으나 현재 작업 공간에서 Sites 호스팅이 활성화되지 않아 사이트 생성을 시작할 수 없었음.
- 기존 `https://iruvy.com/`은 Caddy가 제공하지만 이 저장소에는 서버 접속 정보, 배포 명령, 자동 배포 설정이 없음.
- 따라서 이번 작업은 릴리스 후보 커밋까지 완료하며 운영 반영에는 기존 서버 배포 권한 또는 호스팅 기능 활성화가 필요함.

외부 자료가 필요한 비차단 항목:

- `26.6% → 93.3%`, `23명`, `약 300m` 실증의 원 보고서 또는 공개 가능한 요약본
- 현재 Iruvy 이름이 반영된 최신 앱 화면
- 문의 양식을 직접 전송할 서비스와 자격 증명
- 기존 `iruvy.com` Caddy 서버의 정확한 배포 명령 또는 자동 배포 연결 정보

콘텐츠와 문의 항목은 안전한 설명과 이메일 기반 대체 흐름으로 우회하여 작업을 완료함.
