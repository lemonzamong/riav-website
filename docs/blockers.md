# 외부 확인과 미결 항목

- 기준일: 2026-07-20

## 이메일 발송

문의 저장과 접수 번호 반환은 운영 중이다. 다만 `/etc/iruvy-contact.env`의 SMTP 사용자명은 설정되어 있고 비밀번호는 비어 있어 내부 알림과 문의자 접수 메일은 아직 실제 발송되지 않는다.

필요한 것은 일반 Gmail 비밀번호가 아니라 `iruvy.official@gmail.com` 계정의 2단계 인증 후 발급한 Gmail 앱 비밀번호다. 자격 증명이 준비되면 서비스 재시작과 `retry-notifications` 명령으로 실패 건만 다시 보낼 수 있다.

## 공개 권한과 회사 정보

- 8개 기관·공간의 실명, 로고, 사진과 인용 공개 허가서
- 26.6% → 96.7%, 90명 중 87명, 약 300m 결과의 공개 가능한 원보고서와 검수 책임자
- 회사 주소, 대표 전화, 사업자번호의 공식 확인

확인 전에는 기관 실명·로고를 노출하거나 실증을 유료 고객으로 바꾸어 쓰지 않는다. 확인되지 않은 회사 정보를 만들지 않는다.

## 실기기 접근성

Lighthouse 접근성 100과 정적 검사는 통과했다. VoiceOver, TalkBack, NVDA, 키보드 전용과 200% 확대의 최종 실기기 검수는 사람이 수행해야 한다.

## 운영상 비차단 사항

- 공개 사이트, 문의 저장, CRM 상태, 분석 이벤트와 백업은 운영 중이다.
- 외부 SaaS CRM은 연결하지 않았으며 현재 SQLite 운영 도구가 지정 저장소 역할을 한다.
- 관리형 자동 배포는 없고 SSH 백업 후 변경 파일만 배포한다.
- 실제 기관 20곳 아웃바운드와 1영업일 회신은 사이트 밖 영업 실행이므로 담당자 승인·운영이 필요하다.
