# Strategy — Iruvy 웹사이트

근거: `research/`(벤치마크·표준/조달·청중/반증) + Iruvy 내부 지식. 이 문서는 사이트가 누구에게 무엇을 어떻게 말할지 정한다.

## Primary objective

기관 내부 **챔피언(접근성·편의증진·시설 담당)** 이 예산·심사·조달을 통과해 **무료 SW PoC 문의**로 이어지도록, 홈에서 그를 무장시킨다.

## Primary audience

내부 챔피언(중간관리자). 그는 사이트를 직접 보고, 내부 기안을 써야 하며, 예산이 없다. 홈의 임무는 사용자를 감동시키는 게 아니라 **챔피언이 상급자·감사·예산 앞에서 살아남게** 하는 것. (근거: 청중·반증 리서치.)

## Secondary audiences

- 예산 결정자·시설관리·기관장(챔피언이 설득할 상대) — ROI·리스크·선례 언어.
- 조달·개인정보/보안·법무(veto 보유) — 프라이버시·조달 경로·표준 준수.
- 최종 사용자·장애인 단체 — **증인/정당화 근거**(구매자가 인용). 감정은 이들이 내부에서 운반.

## Core user problem

지도는 건물 입구까지 안내하지만, 진료실·민원창구·상담실·환승구 같은 **실내 실제 목적지**까지는 안내하지 못함. 시각장애인·고령자·초행 방문자는 실내 마지막 거리에서 타인의 도움을 요청해야 함.

## Core organizational problem (구매자의 문제)

기관은 **웹/디지털 접근성 의무(장차법·지능정보화기본법·KWCAG)**·편의증진 요구를 지면서도, 방문객 안내를 여전히 사람이 반복하고, 접근성 성과를 **입증할 근거**가 부족함. 담당자는 새 도입에 **커리어 리스크**를 짐.

## Positioning

> Iruvy는 복합 실내공간을 **길찾기 가능한 데이터로 전환**해, 방문객이 스스로 목적지에 도착하게 하고 기관에는 **접근성 개선을 측정·입증할 근거**를 남기는 실내 내비게이션 인프라. 무료 SW 등록으로 작게 시작하고, 대형 공간은 저비용 보정 장치로 확장.

- 감정 슬로건("누구나 어디든")은 **보조**로, 구매자 문제·결과·의무를 **주**로. (전략 체크포인트 D-HERO 참조.)
- 리드 금지어: 로봇·피지컬 AI·데이터 무어·플랫폼(회사 비전 섹션에 장기 관점으로만).

## Value proposition (구매자에게)

1. 방문객 안내·동행 부담 감소(민원·반복 안내 감소).
2. 접근성 개선을 **숫자로 입증**(도착률·이동시간·이탈·만족도 리포트) → 감사·성과·ESG 근거.
3. **무예산 진입**(무료 SW 셀프 등록) → 리스크 없이 한 구간부터.
4. **무과실 조달 경로**(조달청 혁신제품/시범구매) 활용 가능 → 담당자 리스크 완화.
5. 개인 식별 최소화·온디바이스 지향 데이터 처리 → 프라이버시 veto 대응.

## Key proof points

- 26.6% → 96.7% 자력 도착률(2차 PoC 90명, 팀 제공·제한 명시).
- 평균 이동시간 약 60% 단축(특정 환경).
- 실명 기관 접점: 한양대 학생회관(PoC), 서울대 캠퍼스타운(지원), 서울 AI스마트시티재단(관심·검토), 9호선(협의), KIST 홍릉강소특구(육성·연구).
- "직접 파일럿으로 측정" 제안(자기측정 가능성 = 신뢰).

## Primary objections → responses

| 반대 | 응답 (사이트에 배치) |
|---|---|
| 위치정보 프라이버시(veto 1순위) | 개인 식별 최소화·온디바이스 지향, 처리 항목·기간 계약·정책 명시(기술·개인정보 페이지) |
| 설치·유지 부담 | 무료 SW 셀프 등록으로 시작, 대형만 저비용 장치, 공간 변경 반영 체계 |
| "누가 도입했나"(레퍼런스) | 실명 기관 접점·관계 유형 정직 표기, PoC 사례 |
| ROI·예산 정당화 | 민원·안내 부담 감소 + 접근성 근거 리포트 + 조달 무과실 경로 |
| 조달 경로 | 조달청 혁신제품/시범구매 안내(검증 후) |
| 회사 존속성 | 팀·이력·지원 프로그램·실증 확대 신호 |

## Messaging hierarchy (§7.2)

1. 즉시 이해: 실내 실제 목적지까지 스스로 이동하게 하는 안내 인프라.
2. 관련성: 당신(기관)의 접근성 의무·민원 부담·입증 요구를 해결.
3. 증거: 26.6%→96.7%(제한 명시), 실명 접점.
4. 실행 가능성: 무료 SW로 한 구간부터, 대형은 장치 확장.
5. 신뢰: 실명 기관·조달 경로·프라이버시·표준.
6. 행동: 무료/Light PoC 문의(+ 조달 킷 다운로드).

## Trust strategy

실명 기관 > 익명 로고, 관계 유형 정직 구분, 근거에 n/과제/장소/자기측정 라벨, 실제로 지키는 접근성 선언, 온디바이스·익명화 차별점, 조달 지원물.

## Conversion strategy

낮은 마찰 진입(무료 SW/Light PoC 문의) + 상시 CTA + 조달 킷(원페이지·PoC 제안서 다운로드) 병치. 문의는 mailto 인계(전송 위장 없음) — 서버 수집은 후속 과제(KI-003).

## Content strategy

`docs/CONTENT_STRATEGY.md`. 섹션마다 청중·질문·목표·근거·CTA·접근성.

## Accessibility strategy

`docs/ACCESSIBILITY.md`. WCAG 2.2 AA 실무 기준 — 사이트가 접근성을 **실천**해 신뢰를 얻음(말만 하는 경쟁사와 차별).

## Risks

- 감정 히어로 vs 구매자-결과 히어로 긴장(대표 결정 필요).
- 실증 원자료 미공개(KI-001).
- 규제 과장 리스크(법정 의무로 오도 금지).
- 프라이버시 답변이 약하면 veto.

## Non-goals / 의도적 배제

- 소비자 앱 마케팅 톤, 투자자용 로봇·데이터 서사 전면화, 미검증 재무·정밀도 수치, 익명 로고월, 규제 의무 과장.
