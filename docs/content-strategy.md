# 콘텐츠 전략

## 핵심 문장

`복잡한 실내에서도, 누구나 목적지까지 스스로.`

설명 문장:

`Iruvy Go는 GPS가 닿지 않는 병원, 공공기관, 복지시설, 대학과 전시장에서 사용자의 위치를 추정하고 음성·진동·화면으로 실제 목적지까지 안내하는 실내 내비게이션.`

## 메시지 순서

1. 독립적인 실내 이동
2. 기관의 반복 안내 부담 감소와 접근성 개선
3. 작은 범위에서 시작하는 PoC
4. 실제 사용자 검증
5. 위치추정, 경로 그래프, 운영 도구
6. 공간 지능과 향후 확장

## 근거 등급

| 등급 | 의미 | 공개 표현 |
|---|---|---|
| A | 공개 원문 또는 제출 가능한 보고서 확인 | 수치와 출처 직접 표기 |
| B | 팀 제공 결과와 방법·대상·날짜 확인 | “팀 제공 PoC 결과”와 맥락 표기 |
| C | 관심, 협의, 지원, 육성 | 정확한 관계 동사만 사용 |
| D | 계획 또는 목표 | 반드시 계획·목표로 표현 |

현재 `26.6% → 93.3%`, `23명`, `약 300m`는 B 등급으로 취급함. 공개 원자료가 연결되기 전에는 독립 인증이나 일반 성능처럼 표현하지 않음.

## 기관 관계 표현

- 한양대학교 학생회관: 사용자 PoC 경험
- 서울대학교 캠퍼스타운: 입주 또는 지원 맥락
- 서울 AI스마트시티재단: 도입 관심 및 자료 검토 맥락
- 서울 지하철 9호선: 협의 맥락
- KIST 홍릉강소특구: 육성 또는 연구 접점 맥락

고객 로고 행렬처럼 보이지 않게 관계 유형을 문장으로 설명함.

## 피해야 할 표현

- 근거 없는 “혁신적”, “압도적”, “세계 최초”
- “사용자 이동 데이터를 수집”처럼 감시 우려를 만드는 문장
- 지원 기관을 고객처럼 표현하는 문장
- 협의를 도입 또는 계약으로 오인시키는 문장
- 실제 앱에 없는 로봇, 공간 음향, 자동 운영 기능을 현재 기능처럼 표현하는 문장
