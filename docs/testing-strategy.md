# 검사 전략

## 정적 검사

- 모든 내부 링크와 이미지 경로 존재
- 페이지별 제목, 설명, 대표 주소, 공유 메타 존재
- 한 페이지에 한 개의 `h1`
- 이미지 대체 설명 존재
- 임시 문구, 이전 브랜드명, 빈 링크 없음
- 사이트맵 경로와 실제 경로 일치

## 브라우저 검사

- 홈페이지와 주요 페이지 로드
- 데스크톱 1440px, 모바일 390px, 태블릿 768px
- 모바일 메뉴 열기와 닫기
- 주요 행동이 문의 페이지로 연결
- 문의 입력 검증과 이메일 작성 동작
- 개인 정보와 접근성 페이지 연결
- 콘솔 오류 없음

## 접근성 검사

- 키보드만으로 모든 기능 이용
- 건너뛰기 링크와 현재 위치 안내
- 제목과 랜드마크 순서
- 색상 대비와 초점 표시
- 움직임 축소 설정
- 200% 확대와 작은 화면에서 가로 넘침 없음

## 시각 검사

- 첫 화면에서 제품과 주요 행동 확인
- 한글 줄바꿈과 문단 폭
- 이미지 자르기, 겹침, 레이아웃 이동
- 카드 반복이 과도하지 않은지
- 실제 제품 화면과 설명의 일치

## 최종 실행 결과

- `npm run build`: 통과, 9개 페이지·내부 링크·자산·메타·제목·대체 설명 확인
- `git diff --check`: 통과
- 사이트맵 XML 구문 확인: 통과
- 1440×1000 홈페이지, 제품, 실증 화면 확인: 통과
- 390×844 홈페이지와 문의 화면 확인: 통과
- 390px에서 제품·솔루션·기술·실증·회사·문의·개인정보·접근성 경로 가로 넘침 없음
- 모바일 메뉴 열림 상태, `aria-expanded`, 본문 잠금 확인
- 문의 빈 제출의 첫 필수 항목 초점과 상태 문구 확인
- 검사한 브라우저 콘솔 경고·오류 0건
