## 완료를 증명하는 명령

```bash
node tools/build_marketing_pages.mjs
node tests/check-site.mjs
node --check scripts/site.js
(cd server && python3 -m unittest -v test_contact_api.py)
ssh iruvy-prod 'sudo systemctl is-active caddy iruvy-contact'
```

운영 사이트맵 20개 URL은 모두 200, 임의 누락 URL은 404, HTTP는 HTTPS로 308 전환됐다. Lighthouse 최종 측정은 성능 98, 접근성 100, 모범 사례 100, SEO 100이다.

## 완료 판정

웹사이트의 공개 화면, Go 중심 영업 구조, 문의 저장, CRM, 분석, 보안, 성능과 운영 배포는 완료됐다. 마스터 플랜 전체의 최종 Definition of Done은 아직 충족되지 않았다. 실제 이메일 수신, 기관 공개 권한, 실기기 접근성, 신규 영상 제작과 사이트 밖 영업 실행은 외부 자격 증명·승인·촬영·사람 검수가 필요하다.
