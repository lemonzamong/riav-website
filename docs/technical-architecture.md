# 기술 구조

## 선택

의존성이 없는 정적 다중 페이지 구조를 유지함. 콘텐츠를 보기 위해 자바스크립트를 요구하지 않으며, 자바스크립트는 모바일 메뉴와 문의 보조 같은 점진적 향상에만 사용함.

## 계층

- HTML: 의미 구조, 콘텐츠, 페이지별 메타데이터
- CSS: 토큰, 기본 규칙, 구성 요소, 페이지 변형
- JavaScript: 메뉴 상태, 현재 연도, 문의 이메일 작성 보조
- 정적 검사: 링크, 필수 메타, 제목 계층, 이미지 대체 설명, 파일 존재 확인

## 배포

현재 운영 환경은 Caddy 정적 제공임. 빌드 없이 배포 가능한 구조를 유지하며, 모든 경로는 디렉터리형 `index.html`로 제공함.

운영 반영 전 실행:

```bash
npm run build
```

이후 저장소 루트의 정적 파일 전체를 Caddy 문서 루트에 원자적으로 교체하고 `/`, `/product/`, `/contact/`, `/sitemap.xml` 응답을 확인함. 기존 운영 서버의 실제 명령은 저장소에 없으므로 인프라 담당자가 확정해야 함.

## 안전 원칙

- 비밀값 없음
- 문의 성공 상태를 서버 연결 없이 표시하지 않음
- 외부 글꼴 요청 제거
- 필수 정보는 움직임이나 스크립트 뒤에 숨기지 않음
- 기존 `.html` 주소는 호환성을 고려함
