# Accessibility — WCAG 2.2 AA 실무 기준

근거: `research/secondary/standards_procurement.md`. 이 사이트는 접근성을 **말만** 하는 게 아니라 **실천**해 신뢰를 얻는다(경쟁 차별점). 기존 감사 `docs/accessibility-audit.md` + 이 문서.

## 목표

WCAG 2.2 AA + KWCAG 2.2를 실무 기준으로. 한국 구매자의 강제 훅은 물리시설이 아니라 **디지털 접근성(장차법·지능정보화기본법·KWCAG)** 이므로, 사이트 자체의 접근성이 곧 제품 신뢰의 증거.

## 고수익 체크리스트 (마케팅/정보 사이트)

| 항목 | 기준 | 현재 상태 |
|---|---|---|
| 텍스트 대비 | 본문 4.5:1, 큰텍스트 3:1 | ✅ 독립검토 후 수정(기술 라벨·보라 배경 흰색·단가 고지) |
| 대체 텍스트 | 의미 있는 alt, 장식은 빈 alt | ✅ 이미지 alt 제공(제한: 목업 내 세부 텍스트 일부는 본문 병기) |
| 제목 순서 | h1→h2 논리적, 스킵 없음 | ✅ 회사 Vision h2 복구 등 |
| 키보드 초점 가시성 | 초점 표시 명확(2.4.7/2.4.11) | ✅ `--focus` 유지, 탭 위젯 roving |
| 언어 | `lang="ko"` | ✅ 전 페이지 |
| **타깃 크기 24×24 (신규 2.5.8)** | 터치/클릭 타깃 ≥24px | ⚠ 전수 확인 필요(네비 링크·작은 링크) |
| 200% 확대 / 좁은 화면 reflow | 가로 스크롤 없이 재배치 | ✅ 모바일 오버플로우 0 확인, 200% 재확인 권장 |
| 모션 축소 | `prefers-reduced-motion` 준수 | ✅ CSS 모션 축소 + 히어로 영상 제거로 자동재생 모션 없음 |
| 폼 라벨/오류 | `<label for>`, 오류 안내 | ✅ 문의 양식 라벨·aria-live |
| 랜드마크·skip link | main/nav/footer, 본문 건너뛰기 | ✅ 전 페이지 |
| 링크 명확성 | "여기 클릭" 금지, 목적 명시 | 대체로 ✅(영어 eyebrow는 장식·aria 영향 점검) |

## 구현된 접근성 기능 (사용자 안내에 표기)

- 본문 건너뛰기 링크, 의미 있는 랜드마크.
- 키보드 조작 메뉴·탭 위젯·문의 양식(Esc·화살표·Home/End·포커스 복귀).
- 가시적 초점, 움직임 축소 지원.
- 제품 화면 핵심 내용을 이미지 주변 본문에서도 설명.
- 작은 화면·200% 확대 재배치.

## 알려진 제한 (정직 고지 — accessibility 페이지)

- 목업 이미지 내 모든 시각 정보가 alt에 담기지 않음 → 핵심 흐름은 본문 병기.
- 앱·PoC 환경 접근성은 웹과 별도 검증.
- 자동 도구만 신뢰하지 않고 수동 점검 병행(키보드·초점 순서·스크린리더·확대).

## 후속 점검 (QA 연동)

- 2.5.8 타깃 크기 24×24 전수(네비·인라인 링크·나브 토글).
- 라이트 히어로 전환 후 전 페이지 대비 재확인.
- 스크린리더 1패스(제목 탐색·랜드마크·폼).
- 영어 eyebrow 라벨의 스크린리더 낭독·의미 점검.

## 표기 규율

- WCAG/KWCAG "준수"를 **근거 없이 단정 금지**. "AA를 실무 기준으로 삼는다 + 구현 항목 + 알려진 제한 + 피드백 경로"로 표기(현행 accessibility 페이지 방식 유지).
