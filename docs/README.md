# Iruvy 웹사이트 문서

이 디렉터리는 웹사이트의 전략, 구현 판단, 검증 결과를 한곳에서 추적한다.

- `repository-audit.md`: 변경 전 저장소, 자산, 콘텐츠, 위험 감사
- `project-plan.md`: 단계별 작업과 완료 기준
- `information-architecture.md`: 방문자 흐름, 메뉴, 경로 구조
- `content-strategy.md`: 핵심 메시지, 근거 사용 원칙, 전환 문구
- `design-system.md`: 색상, 글꼴, 간격, 구성 요소, 움직임 규칙
- `technical-architecture.md`: 정적 사이트 구조와 배포 방식
- `decisions.md`: 주요 설계 및 기술 결정 기록
- `qa-checklist.md`: 독립 검토 결과와 수정 상태
- `accessibility-audit.md`: 웹 접근성 검사 결과
- `performance-audit.md`: 자산과 렌더링 성능 검사 결과
- `seo-plan.md`: 검색 및 공유 미리보기 계획
- `testing-strategy.md`: 자동 및 수동 검증 범위
- `progress-log.md`: 날짜순 작업 기록
- `known-issues.md`: 해결되지 않은 결함과 개선 항목
- `blockers.md`: 외부 권한이나 자료가 필요한 항목
- `release-report.md`: 최종 결과, 배포, 제한 사항
