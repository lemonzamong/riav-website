# Project Brief

## 목표 (objective)
기관 내부 챔피언이 무료/Light PoC 문의로 전환하도록, Iruvy 실내 접근성 내비게이션을 공개 웹에서 설득한다.

## 대상 (audience)
1차: 내부 챔피언(접근성·편의증진·시설 담당). 2차: 예산·시설·기관장·개인정보/조달. 수혜자·증인: 시각장애인·이동약자·초행 방문자·장애인 단체. (`docs/AUDIENCE.md`)

## 사용자 문제
지도는 건물 입구까지만. 진료실·민원창구·상담실 같은 **실내 실제 목적지**까지는 안내 못 함 → 이동약자는 타인의 도움 필요.

## 기관(비즈니스) 문제
디지털/편의증진 접근성 의무 + 안내 반복 부담 + 접근성 성과 **입증 근거 부족** + 담당자 도입 리스크.

## 성공 기준
- 챔피언이 사이트만으로 내부 기안·예산 방어에 필요한 근거·언어를 얻음.
- 무료/Light PoC 문의 발생.
- 접근성·정직성·최신성에서 전문가·구매자 신뢰.

## 제약
- 정적 사이트, 수동 배포(KI-004), 문의 mailto(KI-003), 실증 원자료 미공개(KI-001).
- 대외 공개·근거·라이브 배포는 대표 확인 후.

## 비목표 (non-goals)
- 소비자 앱 마케팅, 투자자용 로봇/데이터 서사 전면화, 미검증 재무·정밀도 수치, 규제 의무 과장.

## 필수 산출물
- 9페이지 정적 사이트(배포됨), 마스터 프롬프트 문서 체계(docs/·research/·AGENTS), QA·검토·핸드오프.
