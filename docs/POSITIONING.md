# Positioning

## 한 줄

> Iruvy는 복합 실내공간을 **길찾기 가능한 데이터로 전환**해, 방문객이 스스로 실제 목적지에 도착하게 하고 기관에는 **접근성 개선을 측정·입증할 근거**를 남기는 실내 내비게이션 인프라.

## 포지셔닝 규칙 (§7.1)

- 구체·이해가능·구매자 관련·근거 기반·차별화·불필요 전문용어 없음.
- 리드 금지어: AI·로봇·데이터·플랫폼·디지털 트윈·생태계 — 구매자가 이해·평가에 그 단어가 꼭 필요할 때만. 기술은 사용자·기관 **결과**로 번역.
  - 나쁨: "AI 기반 공간 재구성 플랫폼"
  - 좋음: "복잡한 건물에서 방문객이 스스로 목적지를 찾게 하고, 그 개선을 숫자로 남깁니다."

## 차별화 (경쟁 대비)

| 축 | 기존 방식(비콘·QR·LiDAR·UWB) | Iruvy |
|---|---|---|
| 도입 부담 | 설치·유지비·전용 하드웨어 | 무료 SW 셀프 등록으로 시작, 대형만 저비용 장치 |
| 사용자 부담 | 별도 장비·앱 학습 | 자기 스마트폰 음성·진동·화면 |
| 기관 가치 | 안내 기능 | 안내 + **접근성 개선 입증 근거(리포트)** |
| 데이터 | 서버 전송 위주 | 개인 식별 최소·**온디바이스 지향** |
| 조달 | 일반 구매 | **조달청 혁신제품 무과실 경로** 활용 가능 |

(벤치마크 함의: 홈 지표가 이례적으로 강함 → 결과+대상 히어로로 활용. Pointr식 "건물 ROI" 프레이밍은 접근성 구매자에 부적합 → 회피.)

## 카테고리 프레이밍

"실내 지도 앱"이 아니라 **B2B/B2G 실내 접근성 내비게이션 인프라**(안내 + 근거 + 하드웨어 확장 + 기관 리포트). 장기적으로 실내 공간·보행 경로 데이터 인프라 — 단 이 서사는 회사/비전에 한정, 구매자 페이지 전면 배치 금지.

## 프로그램별 각색 (동일 아이템, 강조 전환)

- 복지·사회가치: 이동약자·시각장애인 실내 이동권·사회적 가치·사용자 검증.
- 공공데이터·시민서비스: 공공·복지시설 접근성·민원 안내.
- LBS·위치정보: 실내 위치추정(단, IMU/PDR+그래프 코어, Wi-Fi/RF 보조 위계 유지).
- 스마트시티: 공공시설·시민서비스·AI 사용성·배리어프리.
- 건설·오픈이노베이션: 작업자 위치·위험구역·비상대피·안전 리포트.
- 관광·지역: 외국인·초행·전시/컨벤션·스마트관광.
