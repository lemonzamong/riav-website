# 주요 결정

## 2026-07-10 — 정적 구조 유지

- 맥락: 현재 사이트는 Caddy가 정적 파일을 직접 제공함.
- 검토: Next.js 전환, Vite 전환, 정적 다중 페이지 유지.
- 선택: 정적 다중 페이지 유지.
- 이유: 콘텐츠 중심 사이트에 서버 렌더링과 큰 자바스크립트가 필요하지 않으며 속도, 접근성, 운영 안전성이 가장 높음.
- 대가: 공통 머리글과 푸터의 반복은 자동 검사와 명확한 구성 규칙으로 관리함.

## 2026-07-10 — 공개 메시지에서 데이터보다 이동을 우선

- 맥락: 기존 기술 구역은 데이터 생성을 전면에 둠.
- 선택: 독립 이동과 기관 운영 가치를 먼저, 공간 지능은 기술 페이지와 홈페이지 하단에서 설명함.
- 이유: 주요 구매자의 문제와 개인정보 신뢰에 더 잘 맞음.

## 2026-07-10 — 실증 수치를 팀 제공 결과로 한정

- 맥락: 수치는 일관되지만 저장소에서 원자료를 확인하지 못함.
- 선택: 대상, 과제, 비교 기준을 함께 적고 외부 인증처럼 보이지 않게 함.
- 대가: 강한 마케팅 효과는 다소 줄지만 신뢰성과 검증 가능성이 높아짐.

## 2026-07-10 — 기관 관계 표현 하향 조정

- 맥락: 서울 AI스마트시티재단이 `도입`으로 표시됨.
- 선택: 확인 가능한 맥락인 `도입 관심·자료 검토`로 표현함.
- 이유: 협의와 실제 도입을 혼동하지 않기 위함.

## 2026-07-10 — 홈페이지 대표 매체를 공식 영상으로 전환

- 맥락: 연출 병원 사진보다 실제 제품 사용 장면이 포함된 공식 홍보영상이 제품 이해와 신뢰에 더 유리함.
- 선택: 병원 사진을 홈페이지에서 완전히 제거하고 공식 유튜브 영상을 첫 화면의 주 매체로 배치함.
- 재생 방식: 브라우저 정책을 고려해 음소거 자동 재생으로 시작하며 유튜브 조작 버튼으로 소리와 전체 화면을 선택 가능하게 함.
- 개인정보 보호: 일반 유튜브 주소 대신 `youtube-nocookie.com` 삽입 주소 사용.
- ⚠ 2026-07-11 이 결정은 아래 "하이브리드 히어로"로 **대체됨**(영상 히어로 제거).

## 2026-07-11 — 전략 체크포인트: 히어로 프레이밍 → C(전면 재구성) 채택·배포

- 맥락: 리서치 수렴 — 1차 청중=내부 챔피언, 챔피언은 예산 심사에 **의무+결과** 언어 필요. 감정 슬로건+앱 우선 히어로는 시혜적·nice-to-have로 분류돼 예산 방어에 불리할 수 있음(청중·반증 리서치). 벤치마크도 결과+대상 히어로 권고.
- 옵션: A 현행 유지 / B 비주얼 유지 + 헤드라인만 전환 / **C 홈 전면 재구성**.
- **대표 결정: C.** 깔끔한 앱 목업 비주얼은 유지하되 홈을 구매자 의사결정 흐름으로 재구성.
- 반영(배포됨):
  - 히어로 헤드라인을 감정 슬로건("누구나 어디든")에서 **구매자-결과**("건물 안 실제 목적지까지 안내하고, 접근성 개선을 숫자로 남깁니다")로 교체. 앱 목업·라이트 비주얼 유지. CTA 보조를 "실증 결과 보기"(#results)로.
  - 섹션 순서 재배열: 히어로 → **결과(96.7%)** → **문제(입구까지 vs 실제 목적지)** → 대상별 → 작동 → 시설 → 레퍼런스 → **안심(프라이버시·무료 도입·조달청 혁신제품)** → 도입 단계 → CTA.
  - 신규 섹션: 문제 정의 밴드, 도입 안심(위치정보 보호·무료 SW·혁신제품 검토 = veto 3종 대응).
  - 감정 문구("누구나, 어디든 갈 수 있도록")를 마무리로 강등. title/og를 구매자-결과로.
- 검증: 데스크톱/모바일 육안, 섹션 순서·단일 h1·오버플로우 0·안심 카드 확인. check-site 통과.
