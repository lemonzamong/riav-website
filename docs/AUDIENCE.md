# Audience — 결정 지향 청중 모델

전체 상세: `research/notes/audience_and_disconfirming.md`. 이 문서는 사이트 판단에 쓰는 정본 요약.

## 핵심 원칙: 돕는 사람 ≠ 사는 사람

최종 사용자(시각장애인·고령자·이동약자·초행 방문자)는 제품을 **경험**하지만 구매 권한이 거의 없다. 이들은 **증인·정당화 근거**다 — 구매자가 내부 심사에서 인용하는 증거. 홈은 사용자를 감동시키는 곳이 아니라 **구매자를 무장시키는** 곳.

## 1차 청중 (홈이 겨냥) — 내부 챔피언 (Persona A)

기관의 접근성·편의증진·시설 중간관리자.

- 역할·맥락: 병원·공공기관·복지·대학·교통시설에서 접근성/민원/시설 개선을 담당. 내부 기안으로 예산·도입을 발의.
- 목표: 접근성 성과를 만들고 입증. 민원·안내 부담 감소. "일 잘한다"는 평가.
- 제약: 예산 없음/적음. 새 도입 리스크 회피. 상급자·감사·조달을 통과해야 함.
- 두려움: 실패 시 커리어 리스크. "검증 안 된 스타트업" 낙인. 프라이버시 사고.
- 승인 경로: 기안 → 예산/시설/기관장 → (개인정보·보안·법무 veto) → 조달.
- 정보 요구: 무예산 진입, 근거(도착률 등), 실명 레퍼런스, 프라이버시 답, 조달 경로, 도입 규모/부담.
- 언어: 편의증진·웹접근성 의무, 민원 감소, 성과 지표, 시범도입, 무과실 조달.
- 근거 임계치: n·과제·장소 있는 수치 + 자기측정 라벨. 직접 파일럿 가능성.
- 개인적 성공: 상급자·감사 앞에서 방어 성공, 저리스크로 성과. 실패: 예산 낭비·사고로 책임.

**왜 1차인가:** 한국 B2G는 내부 기안 없이 안 움직이고, 실제로 사이트를 보는 사람이 챔피언이며, 무료 SW 파일럿이 그의 무예산 제약에 정확히 맞음.

## 2차 청중

| 페르소나 | 관심 | 믿어야 할 것 | 결정 바꾸는 근거 |
|---|---|---|---|
| 예산 결정자 (B) | ROI·선례·리스크 | 낭비 아님, 성과 입증 | 비용 대비 민원 감소·근거 리포트·무과실 조달 |
| 시설/운영 관리 (D) | 설치·유지 부담 | 운영이 감당 가능 | 무료 SW 시작·공간 변경 반영·저비용 장치 |
| 기관장/임원 (E) | 대외 성과·안전 | 평판 이득·리스크 관리 | 접근성 성과·ESG·안전 근거 |
| 개인정보/보안·법무 (veto) | 위치정보 처리 | 개인 식별 최소·근거 있는 처리 | 온디바이스 지향·처리 범위 계약·정책 |
| 조달 | 구매 근거 | 정식 경로 존재 | 조달청 혁신제품/시범구매 |

## 수혜자·정당화 세력 (증인)

시각장애인·고령자·이동약자·초행/외국 방문자 + 장애인 단체(한국시각장애인연합회 등). 이들의 경험·지지가 구매자의 내부 명분을 정당화. 감정은 이들이 내부에서 운반 → 사이트는 과잉 감정 대신 근거를 제공.

## 함의

- 홈 헤드라인·순서를 챔피언 기준으로: 구매자 문제 → 기관 결과 → 정직한 근거 → 실명 레퍼런스 → 프라이버시 → 설치/유지 → 조달 → 무료 파일럿 CTA. 감정 한 줄은 마무리 근처.
- 미응답 반대(프라이버시·설치/유지·레퍼런스·ROI·조달·존속성) 각각에 답 배치.
