# Iruvy Flow 사이트 전환 런북

## 배포 전

1. 현재 `/var/www/riav`와 Caddy 설정, DNS·MX 레코드를 백업한다.
2. `npm run build`과 `npm test`를 통과한다.
3. `docs/pending-facts.md`의 법적·보안·메일 사실을 팀이 확인한다.
4. 문의 API와 메일 알림을 스테이징에서 실제 제출로 확인한다.

## 배포

1. 새 `dist/`를 별도 릴리스 디렉터리에 업로드한다.
2. Caddy 정적 루트를 새 `dist/`로 전환한다.
3. 과거 제품·가격·솔루션 경로는 410을 반환한다.
4. 홈, 핵심 페이지, sitemap, robots와 문의 API를 확인한다.

## 롤백

1. Caddy 정적 루트를 직전 백업으로 되돌린다.
2. 문의 API와 DNS·MX는 변경하지 않는다.
3. 캐시를 확인하고 홈, 문의와 법적 페이지를 다시 검증한다.

운영 도메인 전환은 대표의 명시적 승인 후 수행한다.
