# 디자인 체계

## 방향

장식적인 인공지능 이미지보다 `출발점 → 경로 → 목적지`를 반복되는 시각 언어로 사용함. 밝은 편집 디자인, 큰 한글 제목, 넓은 여백, 실제 제품 화면을 중심으로 차분하고 정밀한 인상을 만듦.

## 색상

| 토큰 | 값 | 용도 |
|---|---|---|
| `brand-700` | `#503BD7` | 주요 행동, 본문 강조, 흰색 위 텍스트 |
| `brand-600` | `#6753F8` | 경로, 시각 강조, 보조 행동 |
| `brand-100` | `#E9E5FF` | 경로 주변, 어두운 바탕의 보조색 |
| `brand-050` | `#F5F3FF` | 선택 상태와 작은 태그 |
| `ink-950` | `#121218` | 제목과 강한 본문 |
| `ink-650` | `#505160` | 일반 본문 |
| `ink-500` | `#6F7080` | 보조 설명 |
| `surface` | `#F7F7FA` | 구역 구분 |
| `surface-warm` | `#FBFAF7` | 첫 화면과 페이지 머리 |
| `focus` | `#1769E0` | 키보드 초점 |

확인한 주요 대비: `brand-700/white 7.12:1`, `brand-600/white 5.04:1`, `ink-650/white 7.82:1`, `ink-500/white 4.88:1`.

## 글꼴

- Pretendard 자체 제공 WOFF2
- 굵기: 400, 600, 800
- 큰 제목: `clamp()` 기반 유동 크기, 좁은 자간, 균형 줄바꿈
- 본문: 1.0~1.12rem, 행간 1.75
- 문장 폭: 약 45rem 이내

## 간격과 레이아웃

- 최대 콘텐츠 폭: 76rem
- 좌우 여백: 1.25rem에서 4.5rem 사이 유동
- 구역 간격: 5rem에서 9rem 사이 유동
- 주요 반응형 전환: 960px, 760px, 680px
- 모바일에서 모든 다단 구조는 한 단 또는 두 단으로 재배치

## 모서리와 그림자

- 입력과 작은 요소: 0.65rem
- 일반 묶음: 1rem~1.5rem
- 큰 장면과 주요 행동 패널: 2.25rem
- 그림자는 제품 화면과 공간 장면처럼 실제 깊이가 필요한 곳에만 사용

## 구성 요소

- 머리글과 모바일 메뉴
- 채움·윤곽·밝은 버튼
- 지표 띠
- 기능·과정·솔루션 그리드
- 경로선과 출발·도착 지점
- 제품 화면 프레임
- 실증 결과 패널과 근거 표
- 문의 입력과 상태 메시지
- 주요 행동 패널과 푸터

## 움직임

- 버튼 떠오름과 메뉴 표시처럼 상태를 설명하는 짧은 전환만 사용
- 첫 화면 공식 영상만 음소거 자동 재생하고 유튜브 기본 조작 기능 유지
- 시차 스크롤과 스크롤 가로채기 없음
- `prefers-reduced-motion`에서 모든 전환을 사실상 제거
