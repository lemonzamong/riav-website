# 성능 감사

상태: 구현 후 정적 자산 재검사 완료

## 기준선

- HTML 약 18KB, CSS 단일 파일 1,264줄
- 첫 화면 이미지 두 개가 각각 약 220KB
- 사용하지 않는 원본 PNG는 각 1.3MB 이상
- 병원 장면 이미지 약 1.9MB
- 로컬 Pretendard OTF 5개 합계 약 7.5MB
- 외부 Pretendard CDN과 구글 Inter를 CSS에서 차단형으로 다시 요청
- 자바스크립트 없음

## 개선 방향

- 외부 글꼴 요청 제거, 필요한 굵기만 자체 제공 WOFF2로 변환
- 큰 이미지는 WebP 또는 최적화 JPEG로 제공하고 명시적 크기 지정
- 첫 화면 외 이미지는 지연 로드
- 영상은 포스터만 먼저 보이고 사용자가 재생할 때 로드
- 자바스크립트는 작은 공용 파일 하나로 제한
- 콘텐츠 렌더링은 스크립트와 무관하게 유지

## 적용 결과

| 항목 | 결과 |
|---|---:|
| 홈페이지 HTML | 약 17KB |
| 전체 CSS | 약 20KB |
| 공용 JavaScript | 약 2.9KB |
| 자체 제공 글꼴 3개 합계 | 약 156KB |
| 첫 화면 공간 장면 | 약 280KB |
| 제품 화면 3개 합계 | 약 552KB, 지연 로드 |
| 초기 외부 글꼴 요청 | 0건 |
| 프레임워크·실행 의존성 | 0개 |

원본 OTF 세 굵기의 합계 약 4.5MB 이상을 실제 페이지 문자 부분집합 WOFF2 약 156KB로 줄임. 첫 화면 장면도 1.9MB PNG에서 280KB JPEG로 줄임. 제품 화면은 명시적 크기를 제공하고 홈페이지에서는 지연 로드함.

## 제한

로컬 정적 서버 기준 감사이며 운영 Caddy의 압축, 캐시 정책, 실제 핵심 웹 지표는 배포 후 별도 측정이 필요함.
