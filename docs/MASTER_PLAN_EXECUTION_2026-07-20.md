- 기준 문서: `pasted-text-1.txt`, 전역 회사·Go·Flow 단일 기준 문서

## 공개 메시지 기준

- 홈의 주력 제품은 `Iruvy Go`다.
- `Iruvy Guide`는 개발·확장 가설, `Iruvy Flow`는 파일럿 준비 단계로 표시한다.
- Go, Guide, Flow를 동등한 상용 제품처럼 배열하지 않는다.
- 기관 관계는 `유료 도입`, `유료 파일럿`, `실증`, `협력`, `지원`으로 분리한다.
- 현재 8개 기관·공간 경험은 유료 고객 수나 매출로 표현하지 않는다.
- `26.6% → 96.7%`는 2차 실증의 도착 성공률이며 위치 정확도로 바꾸어 쓰지 않는다.
- `95%`와 `99.9%`는 정의·환경·원자료가 공개 가능한 상태가 되기 전 핵심 홍보 수치로 사용하지 않는다.
- 기관명·로고·사진·인용은 공개 권한이 확인된 자료만 사용한다.

## 완료 증거

- 페이지·URL·CTA·상태 라벨이 마스터 플랜과 일치한다.
- 모든 공개 수치는 `content/claims.json`에 등록되고 필수 각주와 연결된다.
- 문의 제출은 서버 검증 → 리드 저장 → 접수 번호 → `/thank-you/`까지 운영 중이다. 내부 알림과 접수 사본은 구현됐으며 SMTP 앱 비밀번호 설정 후 실제 수신 검증이 필요하다.
- UTM·랜딩·동의 버전이 리드에 기록되며 개인정보가 분석 이벤트에 포함되지 않는다.
- 모바일, 키보드, 확대, 링크, 메타데이터, 보안 헤더와 운영 서비스가 검증된다.
- 미확인 기관 권한, 사업자 정보와 전화번호는 사실을 만들지 않고 명시적 미결로 관리한다. 외부 CRM 대신 현재 지정 저장소인 SQLite와 운영 CLI를 사용한다.
