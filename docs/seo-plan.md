# 검색 최적화 계획

## 페이지 주제

| 경로 | 핵심 주제 |
|---|---|
| `/` | AI 실내 내비게이션, 접근 가능한 실내 길찾기 |
| `/product/` | 음성·진동·화면 실내 안내, 운영자 공간 관리 |
| `/solutions/` | 병원·공공기관·복지시설·대학·전시장 실내 안내 |
| `/technology/` | Wi-Fi·RF·센서 기반 실내 위치추정과 경로 그래프 |
| `/proof/` | 시각장애인 사용자 실내 이동 PoC |
| `/company/` | Iruvy 회사와 제품 비전 |
| `/contact/` | 실내 내비게이션 PoC 문의 |

## 필수 구현

- 페이지마다 고유한 제목과 설명
- 올바른 대표 주소
- Open Graph와 큰 이미지 카드
- 조직과 제품 구조화 데이터
- 실제 경로를 반영한 사이트맵
- 접근성 있는 제목 순서와 설명형 링크
- 검색어 반복보다 시설 문제와 해결 방식 중심의 자연스러운 본문

## 구현 결과

- 9개 공개 경로에 고유 제목, 설명, 대표 주소 적용
- 주요 마케팅 경로에 Open Graph와 큰 이미지 카드 연결
- 홈페이지에 조직 구조화 데이터 적용
- 새 경로와 2026-07-10 변경일을 반영한 사이트맵 갱신
- 로봇 수집 허용과 사이트맵 위치 유지
- 이전 `/privacy.html`, `/support.html` 링크를 새 경로로 연결
