## 목표

1. 방문자가 5초 안에 Iruvy의 제품, 대상, 핵심 이득을 이해하도록 함.
2. 기관 담당자가 작은 PoC에서 시작할 수 있다는 확신을 얻도록 함.
3. 기술 검토자가 입력, 처리, 출력과 확장 방식을 이해하도록 함.
4. 검증 수치와 기관 관계의 범주를 과장 없이 구분함.
5. 접근성 제품을 만드는 회사다운 웹 접근성을 구현함.

## 의존 사항

- 공개 가능한 실증 원자료는 외부 자료가 필요함. 없을 때는 팀 제공 결과와 측정 맥락을 명시함.
- 실제 문의 전송 서비스는 자격 증명 또는 외부 연결이 필요함. 연결 전까지 이메일 작성 흐름을 명확히 제공함.
- 최종 배포는 현재 운영 서버 배포 방식 또는 Sites 배포 가능 여부에 따라 결정함.
