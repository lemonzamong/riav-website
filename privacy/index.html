개인정보 처리방침

시행일: 2026년 7월 10일

1. 웹사이트 문의

현재 웹사이트의 문의 양식은 입력 내용을 Iruvy 서버로 직접 전송하거나 저장하지 않고 사용자의 이메일 앱으로 넘깁니다. 사용자가 이메일을 전송하면 이름, 기관명, 회신 이메일, 시설 유형, 일정과 문의 내용이 이메일을 통해 처리됩니다.

2. 앱과 PoC에서 처리할 수 있는 정보

  • 선택한 목적지, 건물과 경로 정보
  • 권한을 허용한 경우 현재 또는 근접 위치 정보와 기기 센서 정보
  • 도착 여부, 이동 시간, 경로 이탈과 같은 검증 지표
  • 오류 정보, 기기와 앱 버전, 사용자가 제공한 피드백

실제 처리 항목은 PoC와 서비스 환경에 따라 달라질 수 있으며, 도입 전 목적과 보관 기간을 별도로 안내해야 합니다.

3. 처리 목적

실내 목적지 검색과 길안내 제공, 서비스 안정성 개선, 오류 분석, 사용자 피드백 반영, 기관 도입 검토와 문의 회신을 위해 필요한 범위에서 처리합니다.

4. 보관과 파기

법령이나 별도 동의가 요구하는 기간을 제외하고 처리 목적이 끝난 정보는 지체 없이 파기하는 것을 원칙으로 합니다. PoC별 구체 기간은 참여 안내와 계약에서 정합니다.

5. 제삼자와 외부 서비스

법령상 요구 또는 사용자의 동의 없이 개인정보를 판매하거나 임의로 제공하지 않습니다. 앱 배포, 클라우드 운영, 오류 분석과 이메일 처리에 외부 서비스가 사용될 수 있으며 실제 도입 시 해당 서비스와 처리 범위를 안내합니다.

6. 이용자의 권리와 문의

본인 정보의 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 문의: contact@iruvy.com
